# Aniket — Developer Portfolio

A responsive, dark-themed personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally

1. Download and extract this project.
2. Open the `aniket-portfolio` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code **Live Server** extension.
4. Edit the content in `index.html` and styling in `css/style.css`.

## Before publishing

- Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email.
- Verify the UST Global employment description and technologies against your actual responsibilities.
- Add real GitHub repository links and demos after each project is complete.
- Add a LinkedIn link and downloadable resume only after confirming the correct URLs/files.
- Remove any skill you cannot confidently explain in an interview.
- Update project status labels as work is completed.

## Publish with GitHub Pages

1. Create a new GitHub repository named `Aniket-Git2.github.io` (or use another repository name).
2. Upload the contents of this folder to the repository root. `index.html` must be at the root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The repository's Pages panel will show the live URL.
