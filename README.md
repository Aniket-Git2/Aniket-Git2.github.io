# Aniket Singh — Developer Portfolio

A responsive dark portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html`
- `css/style.css`
- `js/script.js`

## Preview locally
Extract the ZIP and double-click `index.html`, or open the folder in Visual Studio Code and use Live Server.

## Manual GitHub Pages update
Upload the contents of this folder to the repository root. `index.html` must remain at the root, with the `css` and `js` folders beside it.

## Included
- Screenshot-inspired centered hero and navigation
- Downloadable resume in `assets/`
- Rotating role text with reduced-complexity JavaScript
- HealthAxis content based on the provided resume
